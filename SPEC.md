## §I INTERFACES
- api: GET `/api/trust` → 200 `TrustResult` from demo fixture (`demo: true`)
- api: POST `/api/trust` body `TrustReport` JSON → 200 `TrustResult` | 400 `{errors: string[]}`
- file: `TrustReport` = `{schema_version: 1, source: string, synthetic: boolean, metrics: TrustMetric[], questions: TrustQuestion[]}`
  - `TrustMetric` = `{name, definition, grain, owner, metric_type: "simple"\|"ratio", status: "verified"\|"warning"}`
  - `TrustQuestion` = `{question, metric, outcome: "pass"\|"fail"\|"warning", message}`
- lib: `lib/trust-contract.ts` → `validateTrustReport(x): {ok, report?, errors}`, `toTrustResult(report): TrustResult`
- type: `TrustResult` = `{demo, synthetic, metrics, questions, findings: AuditFinding[], score, passed, failed, warnings}`
- page: `/trust` sidebar item "Trust Sprint"
